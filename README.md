# QuizProject 🎯

A collaborative multi-level quiz application with interactive questions and scoring system.

## Features
- **4 Difficulty Levels**: Easy, Mid, Hard, Advanced
- **Navigation**: Next/Previous question buttons
- **Responsive Design**: Works on all devices
- **Clean UI**: Modern and user-friendly interface

## How to Play
1. Select your preferred difficulty level
2. Read each question carefully
3. Choose your answer from the options
4. Navigate between questions
5. View your final score at the end
